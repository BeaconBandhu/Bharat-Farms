# 🌾 Farm Assist – Smart Agriculture Platform

**Farm Assist** (also known as **Bharat Farms**) is a smart, AI-powered platform built to help farmers make informed decisions on what to grow, when to grow, and how to maximize revenue — all using weather data, market trends, crop health analysis, and voice-based support.

---

## 🔍 Features

- 🌱 **Smart Crop Recommendation**  
  Suggests the most suitable crops based on location, season, soil type, rainfall, and budget.

- 🌤 **Weather-Based Advisory**  
  Uses OpenWeatherMap API to provide local weather forecasts and simulate future rainfall patterns.

- 📈 **Market Price Analysis**  
  Allows users to compare prices of different crops and view historical and predicted trends.

- 🧮 **Revenue Estimator**  
  Helps farmers estimate yield, profit, break-even, and ROI across multiple crop choices.

- 🩺 **Crop Health Detection**  
  Uses image analysis (via Dwani.ai Vision) to detect common plant diseases.

- 🗣️ **Speech-to-Text & Text-to-Speech (STT/TTS)**  
  Powered by **Dwani.ai** for multilingual voice interaction (e.g., Hindi).

- 📢 **Government Schemes & Alerts**  
  Displays relevant schemes and sends alerts for weather changes or disease outbreaks.
